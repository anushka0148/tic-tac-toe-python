# Tic-Tac-Toe with Scoreboard

## Problem Statement

I wanted to make a simple Tic-Tac-Toe game using Python that can be
played by two people. The program should let both players enter their
moves, check whether the move is valid, and decide when someone wins or
when the game is a draw. I also added a scoreboard so that the scores
can be kept when more than one round is played.

## Scope

This project is a console-based game and is mainly focused on the basic
Python concepts learned in the course. It includes the game board,
player input, move validation, checking for a winner or draw, and
keeping the scores. The project does not use a database or any external
services.

## Target Users

The game is mainly for two people who want to play Tic-Tac-Toe on a
computer. It can also be useful for students who are learning basic
Python programming and want to understand how a small game works.

## High-Level Features

-   3 × 3 Tic-Tac-Toe board
-   Two players: X and O
-   Players choose positions from 1 to 9
-   Invalid and already-used positions are handled
-   Checks rows, columns and diagonals for a winner
-   Detects a draw when there are no empty positions
-   Keeps the score of X, O and draws
-   Allows the players to start another round
